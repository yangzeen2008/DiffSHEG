# Three.js Face Cap reference model

Lightweight ARKit GLB retained for web-based preview and format tests. It is
not the primary Blender asset because it requires `EXT_meshopt_compression`
and `KHR_texture_basisu` decoders.

- Source: https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/facecap.glb
- Contribution provenance: https://github.com/mrdoob/three.js/pull/22514
- SHA-256: `6BFCE6D0FCBB5839F5102B79733007859FEF7C5DF6D9EB49E2264542810B5F64`
- Morph targets: 52 ARKit-compatible targets; side-specific keys use `_L`
  and `_R` suffixes.

The pull request states that the model was provided by the creator of the
iPhone Face Cap app. Re-check model-specific redistribution terms before using
this auxiliary asset outside internal research or the thesis workbench.
