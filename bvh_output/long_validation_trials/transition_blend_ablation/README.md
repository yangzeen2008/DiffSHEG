# SO(3) 释放帧数消融

本目录固定模型、checkpoint、音频、裁剪范围、随机种子、采样器和窗口重叠，只改变自由区域的 SO(3) 释放帧数。所有视频从左到右均为：`GROUND TRUTH / BLEND0 / BLEND3 / BLEND5 / BLEND7`。

## 复现实验条件

- 模型：`beat_FM_aa_x0_aligned_v1`
- checkpoint：`pck_best.tar`，epoch 479
- 推理：RK4 50 steps，`n_poses=34`，`overlap=24`
- seed：1234
- 样例：quiet、typical、energetic，各 224 帧
- 唯一自变量：`fm_transition_blend = 0 / 3 / 5 / 7`

## GT 归一化的整姿态时序指标

数值为模型指标除以同段 GT；`1.0` 表示与 GT 动态幅度相近。速度、加速度和 jerk 过高通常意味着抖动或跳变，持续过低则提示过度平滑。

| quiet | 0 | 1.068 | 1.284 | 1.443 | 0.639 |
| quiet | 3 | 1.056 | 1.116 | 1.133 | 0.646 |
| quiet | 5 | 0.902 | 0.811 | 0.783 | 0.642 |
| quiet | 7 | 0.752 | 0.632 | 0.622 | 0.639 |
| typical | 0 | 1.228 | 1.397 | 1.460 | 0.818 |
| typical | 3 | 1.199 | 1.170 | 1.098 | 0.847 |
| typical | 5 | 0.989 | 0.745 | 0.636 | 0.839 |
| typical | 7 | 0.853 | 0.567 | 0.493 | 0.828 |

## 结论边界

- `blend=0` 不可接受：典型段和高强度段的 jerk 分别达到 GT 的 `1.46x` 和 `1.98x`，高强度段左前臂边界峰值达到 `108.5°/帧`。
- `blend=3` 已明显缓解跳变，但高强度段 jerk 仍为 `1.36x`，前臂峰值仍约 `44.8°/帧`，安全余量不足。
- `blend=7` 的峰值最安全，但典型段和高强度段速度仅为 GT 的 `0.85x/0.82x`，存在系统性过度平滑。
- `blend=5` 是当前三段上的候选折中：典型段和高强度段速度为 `0.99x/0.96x`，jerk 为 `0.64x/0.92x`，左前臂峰值为 `30.3/31.7°/帧`。
- 安静段在 `blend=3/5/7` 下都保留约 `42–46°/帧` 的边界峰值，因此不能把 `blend=5` 写成全数据最优；还需全验证集统计、边界自适应或外推限幅以及去标签盲评。

完整机器可读指标位于上一级目录的 `transition_blend_ablation.json`。
